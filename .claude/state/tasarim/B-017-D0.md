- (b) GEÇ. Bash çocuğu (uid 1000): `SELFFD3=none` (fd 3 miras alınmadı), `/proc/<claude>/fd/3` = 0 bayt/rc0 (boşalmış), `/proc/<claude>/environ` yalnız `CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR` ADINI gösteriyor (değer yok), `/proc/<claude>/mem` okunamadı (EACCES), diskte token DEĞERİ 0 eşleşme (`INVALIDd0`=0; "sk-ant-oat" eşleşmesi yalnız benim grep komutumun transcript'e yazılması). MCP çocuğu: credEnv boş, kendi fd 3'ü epoll, claude fd 3 EACCES. `kernel.yama.ptrace_scope=1`.
- (c) GEÇ. Taze fd 3 ile `--resume --fork-session` çalıştı (ikinci spawn code 0, success).

## ADR-0036'da revize edilmesi gereken
- Decision 5 `extension`: allowlist tek küme değil, **(sürüm, platform, auth mode)** ile anahtarlanmalı. oauth `schedule` (skill+slash) ekler; plugin kümesi platform/sürüme göre değişir. Açık soru 3 bu yönde kapanır: operatör düğmesi değil, moda duyarlı incelenmiş sabitler.
- Decision 7 / D-3: api_key modunda cbm MCP sızıntısı için `mcp.json` `env` override KANITLI bir azaltımdır; "hiçbir yol yok" ifadesi "MCP için var, Bash için yok" olarak güncellenebilir (takip ADR'si yerine bu ADR'ye kısmi kazanım notu).
- D-2 ölçütündeki "runner/worker log'unda 0 eşleşme" ancak credentialFd uygulandıktan sonra doğrulanabilir; bu deney yalnız fd'nin prlimit+setuid'den geçtiğini kanıtlar.

## Kalıntı riskler
- `/proc/<claude>/mem`: ptrace_scope=1 nedeniyle aynı uid'li çocuktan okunamadı (EACCES). ptrace_scope 0'a düşerse aynı uid'li Bash çocuğu claude belleğinden token okuyabilir; runner uid yalıtımı (attempt başına ayrı uid) bunu azaltır ama tek uid paylaşan tool'lar için risk sürer. Konteyner ptrace_scope'u host'tan gelir; compose'da sabitlenmeli.
- fd 3 claude'da kapanmıyor, yalnız boşalıyor (0 bayt). Tool çocukları claude'dan SONRA doğduğu için değer kurtarılamıyor; yine de kapatma tercih edilir.
- env yolu (Win oauth): token claude'un `/proc/environ`'ında DEĞER olarak kalır (B1env: aynı uid'li çocuk okuyabilir). Win'de fd yok, yalıtım yok (yalnız dev).
- api_key modu: key hem Bash hem cbm çocuğuna tam değerle ulaşır (D6key, B1key). mcp.json env override yalnız MCP'yi kurtarır.
- Windows plugin kümesi (cc-plugin-privacy) Linux'tan farklı; allowlist platforma duyarlı olmazsa fail-closed yanlış tetiklenir.
