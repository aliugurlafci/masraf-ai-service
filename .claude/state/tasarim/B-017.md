# B-017 + B-018 + B-019 + B-020 · tasarım (ADR-0036 Accepted, sözleşme 3.0.0 kullanıcı onaylı)
Kanıtlar: `B-017-deney.md`, `B-017-D0.md`. Kararlar: ADR-0036 Decision 1-13; Opus K8 8.1-8.8 işlendi.
- **Auth:** `CLAUDE_AUTH_MODE=oauth|api_key` açıkça seçilir, varsayılan oauth. İki kimlik bilgisi birden verilirse beş katmanda reddedilir. `CLAUDE_BARE` artık ConfigError.
- **Argv** iki modda aynıdır: `--include-hook-events --restricted --setting-sources user --settings <hardened>`, ardından §10.2'nin 6-16. satırları. `--bare` hiç kullanılmaz.
- **Kimlik bilgisi taşıma:**
  - oauth, POSIX: fd 3 (`credentialFd`). D-1 ve D-2 geçti.
  - oauth, win32: env.
  - api_key: env. `mcp.json` env'i MCP için `ANTHROPIC_API_KEY:""` verir. Bash'e sızıntı kalıntı risk olarak kalır; başlangıçta warn basılır.
- **validateInit kuralları:** `tool`, `tool_missing`, `extension` (sürüm/platform/mod tablosu), `memory`, `auth_source`, `hook_event` (her zaman).
- **Ek kontroller:** logger redaksiyonu; production'da runner `ptrace_scope>=1` değilse başlamaz; B-020 yalnız claude ve probe'a uygulanır.
