# B-015 tasarım notu: Claude'un MCP runtime dizini spawn öncesi doğrulanır (D3-F3-A, K7)

**Hedef:** B-014 kontrolü (manager.ts:210 `prepareLocalRuntimeDir`) yalnız MCP operasyonlarında çalışıyor. `reused_workspace_index` yolunda (pipeline.ts:726, index çağrılmaz) ve task_index başarısız olduğunda (pipeline.ts:750-762, `requireIndex` false ise devam eder) Claude yine `--mcp-config` ile başlıyor (pipeline.ts:857-858). Senkron `claudeMcpConfig` (manager.ts:692) dizine dokunmuyor. Claude spawn'ından önce async doğrulama yap, ayrıca TOCTOU için `os.tmpdir()`'i de kontrol et.

## Arayüz değişikliği
- `McpManager` (types.ts:154 yanına; sözleşme §(contract.md:797) arayüz listesi): `ensureClaudeMcpRuntime(scope: WorkspaceScope): Promise<void>;`. Local modda `prepareLocalRuntimeDir(cacheDir(scope))` çağırır; runner modunda no-op (runtime dizini kiralanan cache, runner `validateSpawnEnvPaths` ile denetler). Hata durumunda `PathEscapeError` (`path_escape`) ya da fs hatası (EACCES, ENOSPC) fırlatır. manager.ts:709 dönüş nesnesine eklenir.
- Orchestrator çağrı noktası: `stages()` (pipeline.ts:362-364) içinde `indexStage()`'den sonra, `runningStage()`'den (Claude run :1015) önce yeni `mcpRuntimeStage()` çalışır, `this.mcpRuntimeOk` alanını yazar. `claudeMcpConfig`'in tek çağıranı pipeline.ts:582 (`prepareWorkspaceFiles`; trace_path grafta 0 çağıran gösteriyor, çağıranı grep ile bulduk). mcp.json yazımı burada kalır, zararsız: mcp=null iken Claude'a verilmez.
- Kullanım: `mcpEnabled` yerine `cfg.mcpEnabled && this.mcpRuntimeOk` ifadesi üç yerde geçer: computeToolPolicy (:801), prompt `index.available` (:827-828) ve request `mcp` (:857). mcp=null olduğunda claude-runner `--mcp-config` vermez, `--strict-mcp-config` kalır (argv.ts:83-84). init doğrulaması `mcpEnabled = r.mcp !== null` (run.ts:480) kuralıyla cbm araçlarını reddeder; bu tutarlı.

## MCP_REQUIRED davranışı
- Tanım: packages/shared/src/node/config.ts:410 (`bool(false)`), :645 (MCP_ENABLED gerektirir). Bugün yalnız worker başlangıcında kullanılıyor: apps/worker/src/runtime.ts:311 (probe başarısızsa başlatmayı reddet) ve :243 (readiness). Orchestrator config'inde bu alan yok. Eklenecek: `mcpRequired: boolean` → packages/orchestrator/src/types.ts:57; eşlemesi apps/worker/src/config.ts:94. Shared config'e dokunulmaz.
- ensure başarısızsa ve `cfg.mcpRequired || project.requireIndex` doğruysa görev fail-closed biter: `path_escape` için `SettleSignal('failed','security_violation', msg)`, diğer hatalar için `('failed','workspace_error')`. Yeni FailureReason gerekmez. Öneri: `requireIndex` de fail-closed tetiklesin. Gerekçe: indeks zorunlu bir projede Claude'u MCP'siz başlatmak bu bayrağın anlamını boşa çıkarır. Opus onayı gerekiyor.
- Aksi halde `event('warning', {warning:'mcp_runtime_rejected', errorCode})` ile birlikte `systemLine` yazılır; Claude mcp.json olmadan başlar. MCP_REQUIRED'ın anlamı başlangıçtan görev başına genişliyor, bu yüzden ADR-0037 önerilir.

## tmpdir kontrolü (yalnız POSIX; win32'de uid yok, kontrol yok)
`prepareLocalRuntimeDir` başında `lstat(tmpdir())` çalışır. Şartlar: dizin olmalı ve symlink olmamalı; `uid ∈ {0, getuid()}`; `(mode & 0o1000) !== 0` (sticky) ya da `(mode & 0o002) === 0`. Tutmazsa `PathEscapeError` atılır (role `tmpdir`, reason `tmpdir_owner` / `tmpdir_world_writable` / `symlink`). Bu yol operasyon, probe ve ensure için ortaktır. Symlink TMPDIR (ör. macOS) reddedilir, fail-closed. `/tmp` (root 1777) ve test-linux `TMPDIR=/tmp/w` (uid 1000, 0700) geçer.

## Sözleşme metni önerisi (2.2.1 → 2.3.0, Mimari)
- §(contract.md:797) arayüzüne: `ensureClaudeMcpRuntime(scope): Promise<void>; // local: creates/verifies the runtime dir Claude's MCP server uses; runner: no-op`.
- §10.11 m.5 local metnine (B-014 önerisinin sonuna): "On POSIX `os.tmpdir()` itself must be a directory (not a symlink) owned by root or this uid, and either sticky or not other-writable; otherwise `path_escape`. The pipeline calls `ensureClaudeMcpRuntime` after the index stage and before starting Claude; on failure the attempt fails (`security_violation`, or `workspace_error` for I/O errors) when `MCP_REQUIRED` (or the project's `requireIndex`) is set, else Claude starts without `--mcp-config` (warning `mcp_runtime_rejected`)."
- contract.md:2595: MCP_REQUIRED açıklamasına görev başına anlam eklenir.

## Geri dönüş
`mcpRuntimeStage` çağrısı `stages()`'ten kaldırılır ve `mcpRuntimeOk` true sabitlenir; davranış B-014 durumuna döner (yalnız operasyon anında kontrol). Metod ve tmpdir kontrolü kalabilir. tmpdir kontrolü üretimde sorun çıkarırsa (sticky olmayan, paylaşımlı TMPDIR) ayrıca geri alınabilir. DB veya şema değişikliği yok.
