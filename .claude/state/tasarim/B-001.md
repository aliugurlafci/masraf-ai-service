# B-001 tasarım notu: CBM_RUNTIME_DIR sözleşmeye işlenmesi (D2-F3-A, P2)

**Hedef:** §10.11 madde 5 ve §10.3 ile kod arasındaki sapmayı kapat. Kod `CBM_RUNTIME_DIR` anahtarını yalnız `mcp` türüne kabul ediyor (validation.ts:26 `MCP_ONLY_ENV_KEYS`, :46); sözleşme anahtarı anmıyor. Yalnız sözleşme düzeltmesi; kod/test değişmez.

## Metin değişikliği (§10.11 madde 5, contract.md:2461, "Server checks" cümlesi)
ÖNCE: `env` keys ⊆ `CLAUDE_ENV_ALLOWLIST ∪ TEST_ENV_ALLOWLIST ∪ {CBM_CACHE_DIR, CBM_ALLOWED_ROOT, CBM_LOG_LEVEL}`, with `ANTHROPIC_API_KEY`, `HTTPS_PROXY`, `HTTP_PROXY`, `NO_PROXY` accepted only for kind `claude`;
SONRA: ... `∪ {CBM_CACHE_DIR, CBM_ALLOWED_ROOT, CBM_LOG_LEVEL}`, plus `CBM_RUNTIME_DIR` for kind `mcp` only; `ANTHROPIC_API_KEY`, ... accepted only for kind `claude`. `CBM_RUNTIME_DIR` MUST be an absolute path that resolves (realpath) to an existing directory inside a path of the spawn's lease (the leased cache `<CBM_CACHE_DIR>/{p,w}/<GUID>`, ADR-0034/0035); otherwise `error {env_rejected}` (`path_escape` cause);
§10.3: `CBM_RUNTIME_DIR` bir allowlist değeri DEĞİL (CLAUDE listesi aynı kalır, kodla birebir: contract.md:2323). §10.3 sonuna tek cümle: "kind `mcp` spawn'ları ek olarak `CBM_RUNTIME_DIR` taşır (§10.11 madde 5)". Changelog 2.2.1 satırı: §10.3, §10.11.

## Kısıtlar
1. Yalnız `mcp` (claude/test için `env_rejected`; validation.test.ts:83-89).
2. Mutlak yol (validation.ts:72; test :90 göreli yol reddi).
3. Lease içi: runner modunda `validateSpawnEnvPaths` (validation.ts:82; lease-manager.ts:416) var olan dizin + lease yolu içinde.
4. LOCAL MOD FARKI (açık belirtilmeli): local.ts:242 yalnız `validateSpawnEnv` çağırır (tür + mutlak yol); `validateSpawnEnvPaths` ÇAĞRILMAZ. mcp-manager local modda runtime dir'i lease dışına koyar: `<os tmpdir>/orc-cbm-rt/<sha256(cache)[:16]>` (manager.ts:160-166; AF_UNIX yol sınırı, cache ile birlikte silinir). Yani "lease içi" kısıtı local mod için UYGULANAMAZ; kısıt yalnız runner/lease-manager moduna aittir. Sözleşmeye: "SANDBOX_MODE=local: lease-içi kontrol yok; dizin mcp-manager'ın per-cache tmp dizini". ADR-0032 (yalnız tek worker/uid varsayımı, ORC_ATTEMPT_ID) ve ADR-0034 ("never runs in local mode" yalnız anchor için; `CBM_RUNTIME_DIR = leased cache` yalnız runner spawn'ı için, :34) local mod için CBM_RUNTIME_DIR kısıtı söylemiyor; ADR-0035:32 da yalnız runner modunu tarif ediyor. Local modda lease-içi kuralı koymak manager.ts davranışını kırar (B-002 sonucuna bağlı: tasarım gereği ise bu metin, değilse local.ts'ye `validateSpawnEnvPaths` + manager.ts'nin local dizinini lease'e taşıma gerekir, o zaman minor/ADR).
